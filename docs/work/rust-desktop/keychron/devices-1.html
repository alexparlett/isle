How it works

The receivers already tell Isle each device's battery, the M7 8K's DPI stages, which is in use and its report rate, and the Q6 Max's Mac/Windows switch. This board puts the mouse's settings where the mouse is set up, raises an OSD when its buttons change them, and shows the keyboard's switch where its Kind is chosen. Isle reads these; it does not write them to the devices (the receivers' set commands are not decoded).

For you to answer

Reply lgtm or name changes. Recommended:

  1. DPI and report rate in Settings › Mouse, in the mouse's own group below Isle's pointer settings, read only, each saying where it is changed.
  2. DPI as the stage table with the stage in use marked (Mouse 1), over one value with the stages in its note (Mouse 2).
  3. Report rate as its value in Hz. Only 1000 Hz is measured; the other five steps are read from the mouse's six and are checked when this is built.
  4. The battery beside the device's name in Mouse's group title and Keyboard's row and page, as Batteries shows it.
  5. An OSD for the DPI button (name, DPI, five stage pips) and one for a report-rate change, as the other OSDs: in place on repeats, shown over games.
  6. Asleep or away, the last values dimmed, with when they were read (Mouse 3), rather than hiding the group.
  7. Keyboard's Automatic names the switch: "Mac (from its switch)" in the list, and the page says which side it is on now.
