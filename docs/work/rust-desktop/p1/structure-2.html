Gate 2, batch 2: questions

Each has a recommendation; the reasoning is in the sheets.

Notifications and Focus

  1. Where banners appear: top right under the strip, or top centre under the island? Top right: centre would cover the window you work in and fight the island's panels.
  2. Lock screen: nothing, each app with a count, or previews? Each app with a count.
  3. Game Mode over a Focus you turned on: Game Mode takes over and gives it back after. Takes over.

Control Centre

  1. A page's head carries its module's switch, so a page opened from a glyph is complete (v1 put no switch on pages). Head carries the switch.
  2. Media in Control Centre: only the Now Playing module, not repeated in Now (changes island.md). Module only.
  3. Game Mode: no module, only its row on the Focus page. No module.
  4. Keys in the grid: arrows move, Space acts, Return opens a page (changes island.md's "Right or Return"). Yes.

Lock and prompts

  1. Greeter: in your wallpaper, appearance and accent, published by your session (never your token file). Yes.
  2. Cmd+Tab with a prompt up: sets the prompt aside into the island, Show brings it back, so you can look a password up first. Set aside.

Spotlight

  1. An assistant ("Ask")? None for now; the web row stays last.
  2. Empty field: just the quick keys, last query back on reopening. Yes.
  3. Clipboard and passwords only in their own scopes, not mixed into general search as v1 did. Own scopes.
  4. Quick Look in Spotlight on Cmd+Y, since Space types into the field. Cmd+Y.

Capture

  1. After a shot: macOS's single thumbnail, or CleanShot's stack with OCR? Single thumbnail; OCR later as Copy text in Quick Look.
  2. Annotation: Markup built into Quick Look, replacing satty. Built in.

Settings and apps

  1. Reopening an app's windows when it starts again (v1), with macOS's "Close windows when quitting an app" off by default. Reopen.
  2. Show changed settings (KDE's highlight) under View, off by default, with Reset to default per row. Yes.
  3. Game Mode's settings fold into Focus and Displays; no pane of its own. Fold in.
