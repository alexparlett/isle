How it works

Software Update checks once an hour for the repositories, the AUR and Isle's own branch. Update Now runs one full upgrade with one password. It keeps running if you close Settings, and Control Centre, the island and the system menu show how far it has got. When the kernel, the graphics driver or Isle itself has been replaced, the page, the menu and the island say a restart is owed until you restart.

For you to answer

Reply lgtm or name changes. Recommended:

  1. One status card at the top of the page in every state, with its buttons at the card's foot, and one row under it for automatic checks.
  2. Update Now as the button's name, as on macOS. Control Centre keeps P1's "Install updates…", which opens this page.
  3. Counts by source on the card. Every package is in More Info…'s sheet, not on the page.
  4. Show Details is closed by default and shows the last lines of output in monospace.
  5. Known failures in plain words (another program installing, no network, disk full, a file conflict); anything else shows pacman's own error line.
  6. A refused password reads "The update didn't start", because nothing changed. It is not shown as a failure.
