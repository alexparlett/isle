The rows and keys are listed in p16/rows.md. Reply lgtm or name changes. Recommended in each case:

  1. Mission Control's two settings are switches in Desktop, both off: rearranging desktops by use, and grouping windows by app.
  2. Stage Manager's options are always in Desktop, with a line saying it is turned on per desktop from Mission Control. Show recent apps is off; windows from an app show all at once.
  3. No "Click wallpaper to reveal desktop" row. On a Stage Manager desktop a click on the wallpaper shows it; on an ordinary desktop it does nothing.
  4. Shortcuts… has a keyboard and a mouse column per action. The keyboard column is the same setting as Keyboard Shortcuts'; the mouse column offers Back, Forward and buttons 6 to 8, with a held modifier, none by default.
  5. A mouse button is stored as another chord in the same shortcuts list as the keys ("Ctrl+Back"), so one action has one list.
  6. The hot corners gain Mission Control, Application Windows and Desktop, leading the menu; bottom left becomes Mission Control.
  7. Keyboard Shortcuts › Desktops gains Mission Control, Application windows and Show Desktop at the top.
  8. Split View's chords are "Full screen tile left" and "right" in Tiling, off by default.
