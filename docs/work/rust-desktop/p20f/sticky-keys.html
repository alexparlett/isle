Sticky Keys Indicator

With Sticky Keys on, a modifier tapped alone applies to the next key (latched), and tapped twice stays down until tapped again (locked). Nothing shows that today, so a locked Ctrl reads as a broken desktop. These are packet 20f.1's two placements, drawn at 1:1 from Isle's tokens. Switch the state to compare.
